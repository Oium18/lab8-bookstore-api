# Bookstore API

REST API для бази даних книжкового магазину.

## База даних

Назва бази даних: bookstore

Основні таблиці:

- books
- authors
- customers
- orders
- order_items
- suppliers

## Основні маршрути API

- GET /books
- GET /authors
- GET /customers
- GET /orders
- POST /books
- PUT /books/:id
- DELETE /books/:id

## Технології

- Node.js
- Express.js
- MySQL
- Git
- GitHub
- GitHub Actions
